Turn any London café into a planter opportunity

View Demo Composites Run the Pipeline

Three phases. Zero manual work.

The engine discovers, validates, and visualises — end to end — without a human eyeballing a single candidate.

Phase 1

Venue Discovery

Google Places API → heuristic filtering (chain detection, operational status, street proximity) → SQLite cache. Produces 50 ranked candidates in ~3 seconds.

Google Places SQLite Cache Heuristic Filter
Phase 2

Image & Validation

Street View primary (heading-derived framing) → Gemini Vision QA gate → fallback to Business Photos + Website Crawler if Street View fails. Only street-facing, unobscured exteriors pass.

Street View Gemini Vision QA Fallback
Phase 3

Compositing

Generative-first (Replicate FLUX Kontext Pro) edits the real frontage photo with natural-language spatial prompts. Falls back to deterministic CV (OpenCV + PIL) on any error.

FLUX Kontext Pro OpenCV Auto-Fallback
